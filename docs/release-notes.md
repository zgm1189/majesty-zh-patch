## 两个版本，按需取一个

| 文件 | 说明 |
|---|---|
| `majesty_zh_lite.apk` | **纯翻译版**。只有中文显示，游戏数值、商店、等级、关卡和官方原版完全一致。推荐给正常游玩的人。 |
| `majesty_zh_full.apk` | **完整版**。翻译 + 一次升 50 级、钻石商店免费、英雄上限 99、建筑上限解除、关卡全解锁、老兵直升 99 级。 |

两个包名相同（`com.herocraft.game.majesty_ne`），**只能装一个**，装另一个会覆盖前一个。

## 这一版去掉了实名认证

原版启动 3 秒后会请求一个远端接口判断地区（渠道 SDK 带的实名认证），
返回 `cn:true` **或者请求失败**都会弹「需完成实名认证后才能开始网络游戏」，要求填中国大陆身份证号。

对外国玩家来说，请求这个国内接口超时是常态，所以基本都会卡在这一步。
这一版把认证回调的注册去掉了，启动后不再发这个请求，也不会弹窗，直接进游戏。
游戏本体、存档位置都没动。原理和验证方法见仓库 `docs/去认证说明.md`。

## 安装

1. 先卸载官方版（签名不同，无法覆盖安装）。**卸载会清掉存档**，介意的话先备份。
2. 安装 `majesty_zh_lite.apk` 或 `majesty_zh_full.apk`
3. 启动弹「更新提示」时点「暂不更新」
4. 进游戏后界面就是中文；左下角语言按钮可以切换语言

之后换版本可以直接覆盖安装（同一签名），存档保留。

## 已知问题

- 菜单里 `PLAYER` 相关的几个标签会显示成截断的 `PLAY&R` —— 引擎按固定字节数截断，英文原文被切了
- 战役选择界面的短标签只显示首字
- 建筑面板个别名称为空（引擎的文本槽位是空的，不是翻译丢失）
