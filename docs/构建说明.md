# 构建说明

从源码到可安装 APK 的完整流程，以及每一步的验证点。

## 0. 环境

| 组件 | 实测版本 | 用途 |
|---|---|---|
| NDK | 27.0.12077973 | `clang` 编 `.so`，`llvm-readelf` / `llvm-objcopy` 查符号与打包二进制 |
| build-tools | 36.0.0 | `zipalign`、`apksigner` |
| Python | 3.12+ | `tools/pack_apk.py` |
| JDK | 17 | `apksigner` 需要 |

`tools/build.sh` 顶部的 `NDK` / `BT` 变量按自己的路径改，或直接传环境变量：

```bash
NDK=/path/to/ndk/toolchains/llvm/prebuilt/linux-x86_64/bin \
BT=/path/to/build-tools/36.0.0 \
bash tools/build.sh apk
```

## 1. 模板 APK：先把加载器塞进 `libs3e_android.so`

游戏只加载自己的 `libs3e_android.so`，不会主动加载我们的 `libzhfont.so`。
改 `AndroidManifest.xml` 或 `classes.dex` 都要重新走一遍 AXML / smali，麻烦且容易把包改坏。
最省事的做法是让游戏自己的 `.so` 在 `DT_INIT` 阶段把我们拉起来。

`libs3e_android.so` 的 `.text` 尾部有一大片连续的 `0x00`（对齐填充），可以直接写代码；
`.dynstr` 末尾也有空闲字节，可以塞字符串。于是：

1. **写字符串**：把 `"libzhfont.so\0"` 写进 `.dynstr` 的空闲区（实测文件偏移 `0x124619`，
   紧跟在 `application/x-www-form-urlencoded\r\n` 之后）。
2. **写 stub**：在 `.text` 的空洞里写一个函数（实测 `0x3702C`）：

   ```asm
   stp  x29, x30, [sp, #-0x10]!
   mov  x29, sp
   nop
   adr  x0, <"libzhfont.so">        ; 0x124619
   mov  w1, #1                      ; RTLD_LAZY
   adrp x16, <GOT 页>
   ldr  x17, [x16, #0x9f8]          ; GOT 里已有的 dlopen 项
   blr  x17
   ldp  x29, x30, [sp], #0x10
   ret
   ```

   复用 GOT 里现成的 `dlopen`，不用改重定位表。
3. **挂到 `.init_array`**：`.init_array` 在文件偏移 `0x14D028`，原本 7 项（`0x38` 字节），
   末尾有空位；把 stub 的虚拟地址追加进去，动态链接器加载完这个 `.so` 就会调它。

做完这三步，`libs3e_android.so` 就从 1 399 056 字节的原始文件变成了「会加载 libzhfont.so」的版本，
**字节数不变**（全部是原地覆盖），所以不需要改 APK 里的任何偏移。

> 这套改动和 `libzhfont.so` 的内容完全无关 —— 换功能只需要换 `libzhfont.so`，
> 加载器那一段两个版本共用。这也是 `pack_apk.py` 只替换一个条目的原因。

模板 APK 还需要一处改动：把 `versionCode` 从 `10530` 抬到 `10600`（`versionName` 1.5.30 → 1.6.00），
否则和已装的原版同版本号，某些 ROM 会拒绝覆盖安装。这一步在 AXML 里改整数，不影响字符串池。

## 2. 编译 `.so`

```bash
bash tools/build.sh so
```

内部就是两条 clang 命令（`ZF_CHEAT` 是唯一区别）：

```bash
# 完整版
clang --target=aarch64-linux-android26 -O2 -fPIC -shared -Isrc -DZF_CHEAT=1 \
      -o build/so/libzhfont_full.so src/zhfont.c build/so/zhfont_ttf.o \
      -ldl -llog -lm

# 纯翻译版
clang --target=aarch64-linux-android26 -O2 -fPIC -shared -Isrc -DZF_CHEAT=0 \
      -o build/so/libzhfont_lite.so src/zhfont.c build/so/zhfont_ttf.o \
      -ldl -llog -lm
```

`zhfont_ttf.o` 是字体子集的二进制对象，脚本会在缺失时自动用 `objcopy` 生成：

```bash
llvm-objcopy -I binary -O elf64-littleaarch64 -B aarch64 zhfont_subset.ttf zhfont_ttf.o
```

代码里用 `_binary_zhfont_subset_ttf_start` / `_end` 两个符号引用它。

### 必查：UND 符号

```bash
llvm-readelf --dyn-syms build/so/libzhfont_lite.so | grep ' UND ' | grep -v '@LIBC'
```

**必须为空。** 允许存在的只有 `libc` / `libdl` 提供的 `@LIBC` 符号。

踩过两次坑：内联汇编写死了 `bl zh_on_hero` 这类 C 函数名，编译器看不到引用，`-O2` 把它当死代码删掉，
`.so` 里留一个 UND，`dlopen` 直接失败 —— 现象是「APK 装上了，进游戏一点反应都没有，logcat 也没有」。
对策是给这些函数加 `__attribute__((used))`。`build.sh` 每次编译都会跑这个检查。

### 必查：两版的符号差异

```bash
llvm-readelf -s build/so/libzhfont_full.so | grep -oE 'zh_cheat|zh_cmd2|zh_on_hero|zh_on_unit'
llvm-readelf -s build/so/libzhfont_lite.so | grep -oE 'zh_cheat|zh_cmd2|zh_on_hero|zh_on_unit'
```

完整版四个都有，纯翻译版**一个都不该有**。这是「纯翻译版不含作弊代码」最直接的证据。

## 3. 打包

```bash
bash tools/build.sh apk            # 两个都出
bash tools/build.sh apk lite       # 只出纯翻译版
```

`tools/pack_apk.py` 做的事：

- 逐条复制模板里的条目，**保持各自原来的压缩方式**（`resources.arsc` 必须 `STORED`，
  否则 Android 11+ 报 `INSTALL_PARSE_FAILED_NOT_APK`）
- 丢掉 `META-INF/*`（旧 v1 签名留着会让 `apksigner` 报错）
- 用新的 `libzhfont.so` 覆盖 `lib/arm64-v8a/libzhfont.so`
- 自检：`libzhfont.so`、`assets/translate.dat`、`resources.arsc`、`classes.dex` 都在，
  且 `resources.arsc` 仍是 `STORED`

然后 `zipalign -p -f 4` + `apksigner sign`（v1 + v2）。

## 4. 安装与验证

```bash
adb install -r --no-incremental build/out/北方的扩张_纯翻译版.apk
```

> **`--no-incremental` 不能省。** 不带它，`adb install -r` 可能走 Incremental Install，
> 把包整个卸掉重装，`/sdcard/Android/data/<包名>/` 下的存档一起没了。这个坑真的踩过，存档没救回来。

装好后进游戏：

1. 启动会弹「更新提示」，点「暂不更新」（约 43% 宽、88% 高处）
2. 左下角语言按钮（显示 `ENGLISH`）可以切换语言
3. 顶部四个卷轴：档案 / 设置 / 成就 / 帮助

界面文字应显示为中文。如果还是英文，先确认 `assets/translate.dat` 在包里、大小 752 172 字节左右。

纯翻译版**不会有**任何作弊入口 —— 没有额外的屏幕按钮，没有命令文件通道，
游戏数值和原版完全一致。

## 5. 签名

`build/poc.keystore`（alias `poc`，storepass / keypass 都是 `android`）。
证书 SHA-256：`5F:FB:31:7D:5D:BD:D6:0B:85:3B:1C:A1:A3:23:BD:F5:CB:75:D6:B1:5C:E9:26:05:0A:57:DF:4E:9A:70:78:2E`

和官方签名不同，所以**第一次装必须卸载官方版**；之后装同 keystore 的版本可以直接覆盖，
存档保留。

## 6. 两个版本的维护约定

- 新增功能前先想清楚：它要不要写游戏内存？要写，就放在 `#if ZF_CHEAT` 里面。
- 纯翻译版只允许做两件事：**读**引擎对象（`font`、图集、码表），**写**引擎自己的字体图集和码表。
- 每次出包都跑一遍第 2 节的两个「必查」。符号检查过了，行为检查才有意义。
